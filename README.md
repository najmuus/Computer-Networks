# Computer Networks — AI-Enabled OBE Course Website

Static GitHub Pages website for course U24CS501, based on the supplied Computer Network lesson plan.

## Files
- `index.html` — course pages and content
- `styles.css` — responsive layout
- `script.js` — interactive IPv4 subnetting activity

## Publish with GitHub Pages
1. Create a GitHub repository named `computer-networks-obe-course`.
2. Upload these files to the repository root and commit.
3. Open **Settings → Pages**.
4. Under build/deployment, choose **Deploy from a branch**, branch `main`, folder `/(root)`, and save.
5. After deployment, open the URL shown by GitHub Pages. Expected URL pattern: `https://YOUR-GITHUB-USERNAME.github.io/computer-networks-obe-course/`.

## Security
This is a static public site. It does not implement login, store student data, or use API tokens. Never put secrets, access tokens, API keys, or identifiable student information in public files.

## Course data
The course title, code, units, CIE/SEE marks and references follow the supplied lesson plan. Proposed COs are labelled as proposed and require institutional approval.
