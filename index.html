COURSE CONTENT

Explore the five units

UNIT 01

Introduction and Overview

Data communication, Internet, protocols, standards, OSI, TCP/IP, transmission modes and multiplexing.

Practice prompt

Trace a web request through the OSI and TCP/IP models. For each layer, identify the data unit and one protocol or function.

UNIT 02

Data Link and MAC

Error detection/correction, block coding, CRC, framing, flow control, ARQ, sliding windows, ALOHA and CSMA.

Practice prompt

Compare Stop-and-Wait ARQ and Go-Back-N for a link with occasional frame loss. State the trade-offs.

UNIT 03

Network Layer

Switching, logical addressing, IPv4/IPv6, tunnelling, ARP/RARP, BOOTP/DHCP, ICMP/IGMP and routing.

Practice prompt

Given an address and prefix, determine the network and broadcast addresses. Explain each binary step.

UNIT 04

Transport Layer

Process-to-process delivery, UDP, TCP, traffic, congestion control and quality of service.

Practice prompt

Choose TCP or UDP for file transfer, live voice, and DNS queries. Justify each choice and its limitations.

UNIT 05

Socket Programming and Applications

Socket addresses, system calls, DNS, email, SNMP and multimedia.

Practice prompt

Sketch the client-server sequence for a TCP connection and identify where bind, listen, accept, connect, send and receive fit.

EXPERIENTIAL CASE

Campus connectivity incident

One building can access the LMS, another sees intermittent timeouts, DNS works for some users, and video calls degrade at peak time.

  1. Draw a logical topology and mark the default gateway.
  2. Propose safe tests to distinguish DNS, routing, DHCP and congestion issues.
  3. Record evidence before proposing a fix.
  4. Explain which OSI layers are involved and how recovery will be verified.
